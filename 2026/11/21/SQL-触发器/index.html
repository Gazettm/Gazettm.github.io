SQL:触发器

Author: Gazettm Date: 十一月 21, 2026  17:21:03 Category: SQL

触发器

假设我们有一张课程表，想知道一门课什么时候被新增、改名或者删除。可以在应用里每次改完课程再补一条日志，但如果有人直接在 MySQL 里改表，这条日志就漏了。这里可以把写日志的操作放进触发器，表里的行一有变化，MySQL 就会自动执行对应的语句。

前面写的存储过程要用 CALL 调用。触发器绑在表上，执行 INSERT、UPDATE 或 DELETE 时会触发。BEFORE 和 AFTER 分别表示在当前行操作之前和之后。MySQL 的触发器是按行执行的，FOR EACH ROW 就是这个意思。

OLD和NEW

触发器里面可以用 OLD.列名 和 NEW.列名 读当前这一行的数据。

事件 OLD NEW
INSERT 无 新插入的行
UPDATE 修改前的行 修改后的行
DELETE 删除前的行 无

比如把 Spring 改成 Spring Boot，在更新触发器里，OLD.name 是 Spring，NEW.name 是 Spring Boot。我们可以把两个值都写进日志。

这里每个触发器的主体都只有一条 INSERT，直接写在 FOR EACH ROW 后面就行。下面的校验要写多条语句，就用 BEGIN ... END 把它们包起来。

插入前处理课程名

有时从表单拿到的名字前后带空格。这里再加一个 BEFORE INSERT 触发器，在存入之前用 TRIM 去掉首尾空格。如果处理完只剩空字符串，就用 SIGNAL 报错。

OLD 是只读的。这个例子能写 SET NEW.name，是因为插入还没发生。AFTER INSERT 读到的 NEW.name 已经是处理过的值。

查看和删除触发器

SHOW TRIGGERS 列出当前数据库的触发器。这里只保留和例子有关的几列。

要看某一个触发器的完整定义，可以用 SHOW CREATE TRIGGER。练习结束后可以把这四个触发器删掉。

DROP TRIGGER 可以写成 DROP TRIGGER IF EXISTS trigger_demo.trg_course_ai;，省略库名时就从当前数据库里找。删除后 SHOW TRIGGERS 返回空结果，日志表里仍有 4 条记录。删除触发器只会停止后续的自动操作，之前写下来的日志还在表里。
