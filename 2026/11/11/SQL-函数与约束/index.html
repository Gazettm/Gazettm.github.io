SQL 函数与约束

函数

MySQL 的内置函数可以用来处理字符串、计算数值、操作日期和按条件返回结果。先选中一个练习数据库。下面的查询示例共用一张临时员工表，建表和运行示例要在同一个 MySQL 连接里完成。

字符串函数

函数 功能
CONCAT(s1, s2, ...) 把多个字符串拼接起来
LOWER(str) 转为小写
UPPER(str) 转为大写
LPAD(str, n, pad) 在左边填充 pad，使结果达到 n 个字符
RPAD(str, n, pad) 在右边填充 pad，使结果达到 n 个字符
TRIM(str) 去掉首尾的空格
SUBSTRING(str, start, len) 从 start 开始取 len 个字符，从左边数时第一个字符的位置为 1

例如，把不足 5 位的工号在左边补 0，'27' 就会变成 '00027'。LPAD 在原字符串长于目标长度时会截断，所以这里用 WHERE 只更新不足 5 位的工号。

数值函数

函数 功能
CEIL(x) 向上取整
FLOOR(x) 向下取整
MOD(x, y) 返回 x 除以 y 的余数
RAND() 返回大于等于 0、小于 1 的随机数
ROUND(x, y) 将 x 舍入到指定的小数位数，y 为正时保留 y 位小数

例如，随机生成一个固定 6 位的练习编号。先乘以 1000000 再用 FLOOR，得到 0 到 999999 的整数，最后用 LPAD 补齐前导零。用 ROUND 取整有可能得到 1000000。

日期函数

函数 功能
CURDATE() 返回当前日期
CURTIME() 返回当前时间
NOW() 返回当前日期和时间
YEAR(date) 取年份
MONTH(date) 取月份
DAY(date) 取日，也就是这个月的第几天
DATE_ADD(date, INTERVAL expr unit) 给日期或时间加上指定间隔，例如 INTERVAL 90 MINUTE
DATEDIFF(date1, date2) 用第一个日期减去第二个日期，返回相差的天数，只比较日期部分

流程函数和 CASE 表达式

写法 功能
IF(条件, 值1, 值2) 条件为真时返回值1，否则返回值2
IFNULL(值1, 值2) 值1为 NULL 时返回值2，否则返回值1
CASE WHEN 条件 THEN 结果 ... ELSE 默认值 END 从上往下判断，返回第一个成立的条件对应的结果
CASE 表达式 WHEN 值 THEN 结果 ... ELSE 默认值 END 把表达式的值逐个比较，返回第一个匹配的结果

例如，把成绩分为优秀、及格、不及格和未录入。多个条件可能同时成立，所以先判断 score >= 85，再判断 score >= 60。

约束

约束是数据库对表中数据施加的规则，用来防止写入不符合要求的数据。例如，可以规定员工工号不能重复，或者规定员工填写的部门编号必须能在部门表里找到。

约束 关键字 说明
非空约束 NOT NULL 字段不能为 NULL
唯一约束 UNIQUE 非 NULL 的值不能重复，允许为空的列可以有多个 NULL
主键约束 PRIMARY KEY 唯一标识一行记录，要求非空且唯一
默认值 DEFAULT 插入记录时省略该字段，就使用默认值
检查约束 CHECK 条件为假时拒绝写入，从 MySQL 8.0.16 起支持执行检查
外键约束 FOREIGN KEY 子表中的非空外键值必须能匹配父表中的记录

常用约束示例

下面在当前练习数据库中建一张员工表。编号用 AUTO_INCREMENT 自动生成，工号必填且唯一，姓名必填，年龄要求在 18 到 65 岁之间，状态默认是 '在职'。年龄列同时加了 NOT NULL，因为 CHECK 只会拒绝条件为假的情况，NULL 可能使检查结果为未知。

FOREIGN KEY 外键约束

用部门和员工举例，部门表是父表，员工表是子表。employee_constraint_demo.dept_id 引用 department_constraint_demo.id。两列都用 INT，被引用的部门编号是主键。

  • 建子表时，可以在字段定义后加上 CONSTRAINT 外键名 FOREIGN KEY (外键字段) REFERENCES 父表 (父表字段)。
  • 子表已经存在时，可以用 ALTER TABLE ... ADD CONSTRAINT ... 添加外键。

删除外键时，DROP FOREIGN KEY 后面写的是约束名。例如 ALTER TABLE employee_constraint_demo DROP FOREIGN KEY fk_employee_demo_dept;。

外键的删除和更新行为

ON DELETE 指定删除父表记录时怎么处理引用它的子表记录，ON UPDATE 指定父表被引用的键值发生变化时怎么处理子表。

行为 说明
NO ACTION 默认行为，有子表记录引用时拒绝删除或更新父表的键值
RESTRICT 与 NO ACTION 一样，有引用时拒绝操作
CASCADE 删除父表记录时一并删除对应子表记录，更新父表的键值时同步更新子表外键
SET NULL 删除父表记录或更新父表键值时，把对应子表外键设为 NULL，要求子表外键列允许为空
SET DEFAULT 含义是把子表外键设为默认值，MySQL 默认配置下不可用

例如，把刚才的外键改成级联更新和删除。部门编号从 10 改成 20 后，员工的部门编号也会变成 20。再删除部门 20，对应的员工记录也会被删除。
