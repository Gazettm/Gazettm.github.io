SQL基本语法

DDL

DDL：Data Definition Language，数据定义语言。

DDL数据库操作

  • SHOW DATABASES;展示所有数据库
  • CREATE DATABASE name;创建一个名为name的数据库
  • USE name; 当前使用名为name的数据库
  • SELECT DATABASE();查询当前数据库，返回当前数据库名，如果当下在name数据库中，返回name
  • DROP DATABASE name;删除名为name的数据库

DML

DML：Data Manipulation Language 数据操作语言。

INSERT

  • INSERT INTO tablename (字段名1, 字段名2 ...) VALUES (值1, 值2 ...);向名为tablename的表中指定的字段插入值
  • INSERT INTO tablename VALUES (值1, 值2 ...);向名为tablename表中的所有字段插入值
  • INSERT INTO tablename (字段名1, 字段名2 ...) VALUES (值1, 值2 ...), (值1, 值2); 向名为tablename表中指定字段插入多个值组
  • INSERT INTO tablename VALUES (值1, 值2 ...), (值1, 值2); 向名为tablename表中所有字段插入多个值组
