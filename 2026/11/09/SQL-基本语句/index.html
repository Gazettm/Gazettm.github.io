SQL基本语法

DDL

DDL：Data Definition Language，数据定义语言。

DDL数据库操作

  • SHOW DATABASES;展示所有数据库
  • CREATE DATABASE name;创建一个名为name的数据库
  • USE name; 当前使用名为name的数据库
  • SELECT DATABASE();查询当前数据库，返回当前数据库名，如果当下在name数据库中，返回name
  • DROP DATABASE name;删除名为name的数据库

DML

DML：Data Manipulation Language 数据操作语言。

INSERT

  • INSERT INTO tablename (字段名1, 字段名2 ...) VALUES (值1, 值2 ...);向名为tablename的表中指定的字段插入值
  • INSERT INTO tablename VALUES (值1, 值2 ...);向名为tablename表中的所有字段插入值
  • INSERT INTO tablename (字段名1, 字段名2 ...) VALUES (值1, 值2 ...), (值1, 值2); 向名为tablename表中指定字段插入多个值组
  • INSERT INTO tablename VALUES (值1, 值2 ...), (值1, 值2); 向名为tablename表中所有字段插入多个值组

DELETE

delete指令用于删除表中数据

DQL

DQL（Data Query Language，数据查询语言）用于查询表中的数据。

SELECT 基本查询

方括号里的子句可以按需要添加，实际写 SQL 时不用写方括号。

  • SELECT name, age FROM employee;查询员工的姓名和年龄。
  • SELECT * FROM employee;查询员工表的所有字段。

WHERE 条件查询

SELECT 字段列表 FROM 表名 WHERE 条件;只查询满足条件的数据。

比较运算符 功能
>、>= 大于、大于等于
<、<= 小于、小于等于
= 等于
<> 或 != 不等于
BETWEEN ... AND ... 在指定范围内，包含最小值和最大值
IN (...) 匹配列表中的任意一个值
LIKE 模糊匹配，_ 匹配一个字符，% 匹配零个或多个字符
IS NULL 判断字段是否为 NULL
逻辑运算符 功能
AND 或 && 多个条件同时成立
OR 或 || 至少有一个条件成立
NOT 或 ! 对条件取反

例子里统一用 AND、OR 和 NOT。MySQL 已弃用 &&、|| 和 ! 的逻辑写法，开启 PIPES_AS_CONCAT 时，|| 用于拼接字符串。MySQL 逻辑运算符

聚合函数

聚合函数将多行数据汇总成一个值，例如统计人数或计算平均年龄。

函数 功能
COUNT 统计数量
MAX 求最大值
MIN 求最小值
AVG 求平均值
SUM 求和

COUNT(*) 统计总行数，COUNT(字段名) 只统计该字段有值的行。这里的 MAX、MIN、AVG 和 SUM 也会跳过 NULL。

GROUP BY 分组查询

GROUP BY 将分组字段相同的记录归到一组，通常配合聚合函数使用。分组查询的结果一般选取分组字段和聚合结果。

  • WHERE 在分组前筛选原始记录，条件里只能用这一阶段能取到的值。
  • HAVING 在分组和聚合之后筛选结果，可以用 COUNT(*) 等聚合结果作为条件。

ORDER BY 排序查询

SELECT 字段列表 FROM 表名 ORDER BY 字段1 排序方式1, 字段2 排序方式2;按指定字段对查询结果排序。

  • ASC 按升序排列，省略排序方式时默认使用升序。
  • DESC 按降序排列。

有多个排序字段时，先按第一个字段排序，第一个字段的值相同才比较第二个字段。

LIMIT 分页查询

MySQL 用 LIMIT 起始索引, 查询记录数 取出指定范围的记录。其他数据库的分页写法可能不同。

  • 起始索引从 0 开始，计算方式为 (页码 - 1) * 每页记录数。
  • 查询第一页时可以省略起始索引，例如 LIMIT 10 等同于 LIMIT 0, 10。

DQL 执行顺序

  • 编写顺序为 SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT。
  • 逻辑执行顺序为 FROM → WHERE → GROUP BY（分组并聚合）→ HAVING → SELECT → ORDER BY → LIMIT。

DCL

DCL（Data Control Language，数据控制语言）用于管理数据库用户和权限。

管理用户

查询 MySQL 中的用户可以使用下面两条语句。

  • CREATE USER '用户名'@'主机名' IDENTIFIED BY '密码';创建用户。
  • ALTER USER '用户名'@'主机名' IDENTIFIED BY '新密码';修改用户密码。
  • DROP USER '用户名'@'主机名';删除用户。

MySQL 用 '用户名'@'主机名' 标识账号，例如 'reader'@'localhost' 表示从本机连接的 reader。

权限控制

权限 说明
ALL 或 ALL PRIVILEGES 授予指定层级上的所有常规权限
SELECT 查询数据
INSERT 插入数据
UPDATE 修改数据
DELETE 删除数据
ALTER 修改表结构
DROP 删除数据库、表或视图
CREATE 创建数据库或表
  • SHOW GRANTS FOR '用户名'@'主机名';查询用户的授权。
  • GRANT 权限列表 ON 数据库名.表名 TO '用户名'@'主机名';授予权限。
  • REVOKE 权限列表 ON 数据库名.表名 FROM '用户名'@'主机名';撤销权限。

例如，假设 company 是 employee 表所在的数据库，'reader'@'localhost' 已经创建。
