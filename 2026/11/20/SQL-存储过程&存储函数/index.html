SQL:存储过程&存储函数

Author: Gazettm Date: 十一月 20, 2026  18:41:40 Category: SQL

存储过程与存储函数

假设我们经常要查某个年龄以下的用户。有时要看名单，有时要统计人数。SQL 可以存到数据库里，调用时把年龄传进去，这就是存储过程的一种用法。如果只想把一个值算出来，比如把两百分制换成百分制，也可以写一个存储函数，放到 SELECT 里调用。

下面都在同一个练习库里做。输出来自 MySQL 8.0.46。

存储过程

创建和调用

先写一个按年龄上限查名单的过程。

CREATE PROCEDURE 把查询保存下来，CALL 执行它。这里的 25 是调用时传进去的，过程里的 SELECT 直接把结果集交给调用方。如果原来需要客户端发几条请求才能完成一项操作，也可以把几条 SQL 放到一个过程里，用一次 CALL 发过去。

DELIMITER // 是 mysql 命令行客户端的命令。过程体里有分号，客户端需要等读到 END// 才把整条创建语句交给服务器。建完后用 DELIMITER ; 改回去。这里的 BEGIN ... END 用于把语句放在同一个块里，开启事务则用 START TRANSACTION。

查看定义和已有的过程

SHOW CREATE PROCEDURE 可以看到过程的定义。INFORMATION_SCHEMA.ROUTINES 里同时有过程和函数，所以这里加上了 ROUTINE_TYPE = 'PROCEDURE'。执行到这一步，输出只有一行。

删除时用 DROP PROCEDURE IF EXISTS list_users_by_age;。这个过程后面会和其他例子一起清理。

三种变量

系统变量

@@ 用来读系统变量。以 sql_safe_updates 为例，它有全局值和当前连接的值。先保存会话原值，打开它看一眼，再恢复。

SET SESSION 只改当前连接。对于这类同时有全局和会话值的变量，SET GLOBAL 改的是新连接取到的初始值，已经连接的会话保留各自的值。SET GLOBAL 要有权限，设置本身也不会跨重启保留，长期配置可以写进 MySQL 配置文件。

SHOW GLOBAL VARIABLES LIKE 'sql_safe_updates'; 可以单独看全局值。对这个变量，直接写 @@sql_safe_updates 读到的是会话值。

用户变量

一个 @ 开头的是用户变量，用 SET 赋值就能在当前连接里使用。也可以用 SELECT ... INTO 把一行查询结果放进去。

另开一个连接执行同样的 SELECT @max_age AS max_age, @young_users AS young_users;，两个值都是 NULL。后面接收过程的输出时，CALL 和查 @变量 的语句也要放在同一个连接里。

SET @max_age := 25; 也能赋值。旧代码中还可能见到 SELECT @max_age := 25;，单纯赋值时用 SET 就够了。

局部变量

过程里的临时值可以用 DECLARE 声明。它要放在 BEGIN ... END 块的开头，可以加 DEFAULT，省略时初始值是 NULL。

v_count 只在这个块里使用，每次调用都重新声明。参数 p_max_age 在过程的参数列表中定义。这里用 p_ 和 v_ 区分参数和局部变量，后面写游标查询时能少踩一个同名的坑。

参数和分支

IN、OUT和INOUT

参数 调用时怎么用
IN 传值给过程。省略方向时默认是 IN
OUT 过程写结果，调用结束后从传入的变量里读出来
INOUT 变量先带一个值进去，过程改完再把值写回去

我们写两个例子。第一个传入分数，通过 OUT 拿到等级。第二个把两百分制的分数除以二，再写回原变量。

IF 会从上往下找第一个成立的条件。这里先判断 >= 85，再判断 >= 60，所以 85 分会进入优秀档。@grade_85 只接收输出，调用前可以不赋值。@score 还要提供输入，就先设成 198。

CASE的两种写法

考试类型只有几个固定值，可以写 CASE p_exam_type。分数按区间判断，则用 CASE WHEN 条件。

两个 CASE 的分支里都能执行 SET 等语句，最后用 END CASE 收尾。平时在 SELECT 里写的 CASE ... END 是取值表达式，结尾少一个 CASE。

WHILE、REPEAT和LOOP

用同一个 n 来试三种循环。前两种把 1 到 n 相加，最后一种只加奇数。

  • WHILE 先判断。传入 0 时，循环体一次也不执行。
  • REPEAT 先执行一轮，再判断 UNTIL。传入 0 时，虽然加起来还是 0，repeat_runs 已经变成了 1。
  • LOOP 的退出条件写在循环体里。LEAVE sum_odd 跳出循环，ITERATE sum_odd 跳到下一轮。遇到偶数时，要先减一再 ITERATE，否则下一轮又会读到同一个偶数。

游标和条件处理程序

把符合年龄条件的用户逐行取出来

假设要从 users 中取出年龄不超过 25 的用户，把编号、姓名和职业放进一张表。游标可以把查询结果一行一行交给过程。这里先在当前连接里建一张临时表，后面的 CALL 也在这个连接里执行。

这里有四步。DECLARE ... CURSOR FOR 指定查询，OPEN 打开游标，FETCH ... INTO 按列顺序把下一行交给变量，最后用 CLOSE 关闭。声明放在开头，顺序是局部变量、游标、处理程序，再写实际要执行的语句。

FETCH读到末尾怎么办

FETCH 没有下一行时会产生 NOT FOUND（SQLSTATE '02000'）。我们用 CONTINUE HANDLER 把 v_done 置为真，然后回到 FETCH 后面的 IF。一定要在处理这一行之前检查标志，读完后就直接跳出循环。

把年龄上限改成 19，一开始就没有行可读。第一次 FETCH 后直接退出，临时表中是 0 行。

CONTINUE 执行完处理语句后继续运行，EXIT 执行完会退出声明它的 BEGIN ... END 块。比如写 DECLARE EXIT HANDLER FOR NOT FOUND CLOSE user_cur;，在这个过程的最外层遇到游标末尾时，就会关掉游标并结束整个块。上面的版本用 CONTINUE，于是正常关闭游标的语句可以统一放到循环后面。

处理程序也可以按具体 SQLSTATE 写条件。几个常用的分类是 SQLWARNING（以 01 开头）、NOT FOUND（以 02 开头）和 SQLEXCEPTION（除成功、警告和未找到之外的异常）。

存储函数

前面的百分制换算用 INOUT 时，要先准备一个变量，再 CALL。如果要把换算结果直接放在一条查询里，用函数比较顺手。

函数的参数都是输入参数，定义时直接写名称和类型。RETURNS 指定返回值的类型，RETURN 给出这次调用的结果，所以函数可以直接出现在 SELECT 的表达式里。过程通过 CALL 执行，可以返回结果集，也可以通过 OUT 或 INOUT 传回值。

score_to_percent 只做除法。同一个输入总得到同一个结果，所以声明为 DETERMINISTIC，也用 NO SQL 标明它只计算、不访问表。count_profession 有查询但没有写入，用 READS SQL DATA。人数会随表数据变化，因此这里没有给它声明 DETERMINISTIC。

做完例子可以用 SHOW CREATE FUNCTION 看定义，并删除练习时创建的过程和函数。
